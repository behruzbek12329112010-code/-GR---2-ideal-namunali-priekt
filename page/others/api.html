UZXTECH API Platformasi

Dasturchilar va yirik biznes loyihalar uchun tezkor, xavfsiz JSON API interfeysi.

1. Dasturchilar uchun hujjatlar (API Docs)

Kino bazasini o'zingizning ilovangizga integratsiya qilish uchun quyidagi GET so'rovini yuboring:

GET https://api.uzxtech.uz/v1/movies?api_key=YOUR_KEY

2. Biznes uchun API (API Business)

Kino-teatrlar, tijoriy saytlar va yirik provayderlar uchun sekundiga 10,000 tagacha so'rovni qo'llab-quvvatlaydigan yuqori tezlikdagi serverlar tarmog'i.
